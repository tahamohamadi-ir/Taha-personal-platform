# ADR-0029: P10 Topics/Search/Collections evolution and P11 AI/semantic gate (Draft)

**Status:** Draft (2026-08-24, scaffold). Not yet accepted — requires owner decision (see §7).  
**Date:** 2026-08-24  
**Related:** `Task-list.md` §15 P10 (P10-01..P10-04) + §16 P11 (P11-01..P11-04), `docs/governance/TAXONOMY_GOVERNANCE.md`, ADR-0023 (rebuild trigger), ADR-0027 (unified Compose), ADR-0028 (research graph island), `DEFER-0020`, `master-remaining-work-checklist.md` G1..G5, `docs/status/RISK_REGISTER.md`.  
**Supercedes/amends:** None — extends ADR-0028 collections deferral and ADR-0023 index lifecycle; does not change `RISK-0003` closure or `DEBT-0003` removal.

## Context

P10 (Topics + Search + Collections) and P11 (AI / semantic / knowledge-graph) were queued behind the custom admin rebuild and P8 catalog. Wave 5 shipped the **authorized early slice** of P10: per-locale Pagefind static search (`/{locale}/search/`, `npm run pagefind:index`, noscript browse fallback) without touching taxonomy explosion or FTS (LOG-0215). The owner constraints that gate remaining P10/P11 are:

1. **No tag/collection explosion until governance freezes** — glossary, synonym, and creation rules must be documented and enforced (P10-01), otherwise editorial drift and search dilution follow.
2. **Search must never leak drafts/private or serve stale indexes** — publish/unpublish propagation, permission leak, filters/paging, and drift = disable + browse fallback (P10-04).
3. **FTS is expensive to justify** — PostgreSQL FTS may only be chosen after Pagefind dynamic + benchmark, starting with `simple` if chosen (P10-03 / §14 F9). No vector DB/Neo4j/Redis/Celery on the 4 GiB VPS without explicit owner ADR (§14 H0 + PROJECT_MANIFEST).
4. **P11 AI is gated on P10 quality + privacy + cost + evaluation + human ownership** (P11-01). The codebase today has no pgvector, no graph store, no embeddings, and no AI ingestion — this must stay true until the gate passes.

The VPS is `taha-cms` single Compose (`db` + `cms` + `web` + `caddy` edge) on 4 GiB. Standing up pgvector, a vector DB, Neo4j, or a queues worker violates the current architecture unless a new ADR explicitly raises the resource ceiling.

## Decision (scaffold phase — what is accepted now)

### P10-01 Governance (accepted as docs-first)

- `docs/governance/TAXONOMY_GOVERNANCE.md` is the binding glossary/synonym/creation-rule file. Until owner lifts its freeze, no bulk tag/collection is created.
- `TopicTag` is extended with `description` (glossary entry) and `synonyms` (comma-separated aliases) to carry the glossary into data plus the markdown file. Creation must check `synonyms` collision (see governance §3).
- Canon: `slug` is globally unique ASCII; `name` is locale display; `locale` is independent (`fa`/`en` tags are separate concepts that may share a Latin slug only when intentionally aligned).

### P10-02 Pagefind first (accepted — already live)

- Pagefind remains the **only** search index: post-build per-locale `dist/{locale}/pagefind/` via `scripts/pagefind-index.mjs`; admin/preview paths are never in `dist` so never indexed.
- Scaffold polish in this slice: `/{locale}/search/` adds an `aria-live="polite"` announcement region for keyboard/filter result counts plus empty-state polish beyond the baseline Pagefind UI, without forking Pagefind. No `footprint` change to the no-JS browse fallback. If the index is absent/broken, the page shows `Search index is unavailable. Browse blog, research, or projects from the navigation` (en) / Persian equivalent.

### P10-03 Collections (scaffold model, published-only projection)

- Add `Collection` as a **curated** localized, lifecycle-aware entity: `locale`/`slug`/`title` (via `LocalizedContentMixin`) + `status`/`published_at`/`scheduled_for` (via `LifecycleMixin`) + `description`, `curator_name`, `curator_title` (optional), `criteria` (inclusion prose), `curated_date` (`DateField` nullable), `cover_media` (optional active `Media`), and **explicit** M2M curated members (`articles`, `projects`, `publications` — blank-allowed, editorial-only, filtered to `public()` in projection).
- Admin path: `GET/POST /api/v1/admin/content/collection` and `PUT /api/v1/admin/content/collection/{id}` via the generic content admin router (same OTP+CSRF+If-Match pattern as other entities). Curator/criteria/date are the curation contract — scaffold allows blanks for `draft`, but a follow-up slice will enforce them on `publish` (see §5).
- Public path: `GET /api/collections/{locale}` (paginated) and `GET /api/collections/{locale}/{slug}` — published-only, with member expansions that themselves are filtered to `public()` (no leak). Astro `/{locale}/collections/` and `/{locale}/collections/{slug}/` routes are **not** in this scaffold — they are the next slice after owner content curation (so landing pages stay empty-honest until then; see honesty contract).

### P10-03/§14 F9 FTS (deferred, not scaffolded)

- No `django.contrib.postgres.search` migration, no GIN index, no `SearchVectorField` in scaffold.
- If FTS is ever justified, the next ADR must: (a) record the Pagefind vs FTS benchmark, (b) start with `simple` config, (c) document stemming choice (or none) per locale, (d) keep `public()` as the sole row filter, (e) not index admin/private/internal notes. Do not merge any FTS migration until that ADR is accepted and G1 is closed.

### P10-04 Index lifecycle / release (accepted as rule, partially implemented)

- **Publish/unpublish/archive propagation:** `transition(... to=p/scheduled/archived)` uses row locking + audit (ADRs 0024/0026) and, on `published`, invokes `invoke_static_rebuild()` (ADR-0023) which, when `REBUILD_TRIGGER_ENABLED=true` on the VPS, triggers `rebuild-web.sh` (GHCR pull + `pagefind:index`); if disabled or unreachable the existing artifact is retained (no silent fallback to snapshot when `CMS_API_BASE` is set — build fails honestly per ADR-0027 Slice 3).
- **Permission leak:** every public query path uses `ContentQuerySet.public()` ( `status=published` + `published_at <= now`) and `select_related/prefetch_related` only on `is_active` media. `api.py` and `public_projection.py` are the trust boundary — any new collection/topic projection must call them, not raw `filter(locale=...)`.
- **Filters/paging/rate:** public lists use `PageNumberPagination(page_size=10)` and validated query params (unknown filter → 400); bulk/archive paths are irrelevant to search (no AI bulk).
- **Drift = disable search + fall back to browse:** if `dist/{locale}/pagefind/` is absent or stale (unpublish not yet rebuilt), search must present the browse fallback rather than stale/private hits. Implementation is the `<noscript>` browse list plus the JS `catch` text plus builder honesty (API outage → build fail, no silent snapshot). Owner smoke must probe `/{locale}/search/` for browse links and absence of draft titles; CI must keep `npm run pagefind:index` in the build chain and refuse a dist that contains `admin`/`preview`/`staff` roots.

### P11 Gate (proposed — NOT accepted)

P11 (AI / pgvector / graph / semantic reasoning) **does not ship** in this scaffold. Its entry gate is:

| Gate | Required evidence |
|---|---|
| **P10 quality** | `TAXONOMY_GOVERNANCE.md` freeze lifted (owner), glossaries filled, collections curated with `curator/criteria/date`, Pagefind lifecycle smoke green. No AI until taxonomy is stable. |
| **Privacy ADR** | New ADR explicitly answering: which projections are allowlisted for AI ingest, retention, redaction, and locale/date weighting. No private/admin drafts, inactive media, internal notes, credentials, or PII are ingested — only published public projections (`api.py` allowlist). |
| **Provider / cost / rate** | Which provider/model/vector store, per-request cost ceiling, rate limits, quota, and on-call cost alert. VPS may not host a vector DB or worker fleet without ADR + resource measurement (4 GiB ceiling). |
| **Evaluation corpus & human owner** | Fixed evaluation set (sourced answers with source links, locale-aware, low-confidence/empty states), metric, and a **named human owner** responsible for prompt-injection, citation correctness, and kill-switch. |
| **Evaluation PASS** | Prompt-injection, authorization-leak, citation/locale, cost-limit probes on the fixed set **PASS** in CI/test env — not manual vibes. |
| **Guarded rollout** | Feature flag default-off, per-route expiry, owner kill-switch, incident runbook (`INCIDENT_RUNBOOK.md`), and one-click disable that falls back to P10 Pagefind/browse with zero AI residue. |

Until **all** gates show evidence, branches must not add: `pgvector`/`pg_vector` extension, `pgvector` Python clients, Neo4j/Dgraph drivers, standing embeddings jobs, model API keys in repo, or autonomous publish paths.

## Consequences

- **If this draft is merged as scaffold:** `TopicTag.description`/`synonyms`, `Collection` model + admin/public routes, governance doc, and Pagefind aria-live polish land. No new runtime dependency, no VPS service, no AI code, no FTS. `DEFER-0020` stays OPEN (collections scaffold, not UX-complete); search still Pagefind-only. `WORK_LOG` must record `uv run ... check`, `ruff check`, `pytest -q`, and `npm run build` (with/without `CMS_API_BASE`).
- **If P11 gate never passes:** the site remains a high-quality P10 browse/search/collections corpus — that is an explicit, honest product, not a failure. Disabling AI must restore P10 search/browse without `AI was here` artefacts (P11-04).
- **Negatives if gate lapses:** skipping glossary enforcement → synonym tags and diluted discovery; ingesting private data → privacy breach; autonomous publish without human owner → incident; FTS without benchmark → wasted VPS headroom.

## Threat Model (P11-01 preview — not a launch approval)

- **Do ingest:** published-only fields from `api.py` (`Article`, `Project`, `ResearchTopic`, `Publication`, `Book`, `Talk`, `Download`, `Collection` members) that already pass `is_active`/`visibility`/`is_publicly_projectable()` gates.
- **Never ingest:** `content.*` draft/review/scheduled/archived rows, `AuditLog`, `User`/`Security` internals, inactive `Media.file`, preview tokens, `/staff/` or `/admin/` HTML, CSRF/TOTP secrets, or any unpublished curation. Build-time ingestion must fail closed if CMS is unavailable (no snapshot fallback when `CMS_API_BASE` is set).
- **Not built:** autonomous publish, health/personality inference, student PII, or chat-style memory beyond the single curated static corpus. Any such scope needs a new threat-modelled ADR.
- **Injection & leak vectors:** prompt injection via published bodies must be treated as untrusted content (escape/cite, never execute); collection/topic membership must not expand to restricted evidence/diagrams (they already enforce `is_publicly_projectable()`). Rate/cost exhaustion must be bounded per-IP/per-session with a budget ceiling before responses.

## Alternatives Considered

- **Enable FTS now with `english` + `parsian` configs:** Rejected — no benchmark, no per-locale stemming decision, and no owner review of index lifecycle. See governance §7 and P10-03.
- **Add pgvector in this slice with a local embedding job:** Rejected — violates VPS resource ADR, missing privacy ADR, no evaluation corpus or owner, and would delay honest P10 delivery. Gated to a future ADR after P10 closure.
- **Ship a separate vector DB / Neo4j on VPS:** Rejected under ADR-0027 and manifest VPS ban (Redis/Celery/OpenSearch/Neo4j/K8s forbidden without new ADR).
- **Keep tags as free-form strings on Article:** Rejected — free-form tags explode and break canonical topic pages/collections; `TopicTag` with glossary + curated `Collection` is the intentional editorial model.
